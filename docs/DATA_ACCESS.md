# Data access

Raw EEG is intentionally excluded. Download the datasets from PhysioNet under
their current access and citation terms:

- CHB-MIT Scalp EEG Database (internal patient-independent experiments).
- Siena Scalp EEG Database v1.0.0 (external evaluation).

Never commit EDF files, patient-derived caches, credentials, or private Drive
paths. The `.gitignore` blocks the common raw-data and checkpoint extensions.
