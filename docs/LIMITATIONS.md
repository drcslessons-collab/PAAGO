# Reproducibility limitations

- CHB-MIT inference/training artifacts are not redistributed in this bundle.
- Siena raw EDF files and checkpoints are excluded for licensing and size reasons.
- The external validation uses one public database; it is not prospective or
  long-duration clinical validation.
- PAAGO-F2 shares a checkpoint with PAAGO-F1 and changes the operating policy;
  evidence therefore supports operating-point selection, not an independent
  architectural improvement.
- The test cohort has 14 patients; patient-level uncertainty remains material.
